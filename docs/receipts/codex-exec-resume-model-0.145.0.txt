SCOPE OF THIS EVIDENCE (read before relying on it). This shows the flag is
ACCEPTED, not that it changes the model of an already-open resumed thread. The
two hookprobe receipts capture the actual behavior they claim; this one does not,
and the review flagged the asymmetry. It matters because if codex silently
accepted-but-ignored -m on resume, an override would be recorded in the ledger
(and disclosed in the PR body) as APPLIED while the round in fact ran on the
thread's original model — a dishonest disclosure trail, not just a degraded one.
Bounded: the code falls back to a fresh verify round if the flag is REJECTED, and
a fresh session always applies the model. Strengthening this to a behavioral probe
(two resumed rounds with different -m values, assert the recorded model differs)
is tracked in MANUAL's `## Noticed`.
